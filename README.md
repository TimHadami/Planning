
INSTALLATION SUR IPHONE
========================
1. Ouvre l'URL dans Safari (pas Chrome !)
2. Appuie sur le bouton Partager (rectangle avec flèche)
3. Choisis "Sur l'écran d'accueil"
4. Appuie "Ajouter"

RAPPELS SUR IPHONE
==================
- Nécessite iOS 16.4+ ET Safari
- L'app doit être installée sur l'écran d'accueil
- Autorise les notifications quand Safari le demande
- Les rappels sonnent uniquement pour les tâches DU JOUR
  lorsque l'app est ouverte (ou en arrière-plan sur iOS 16.4+)
- Appuie sur 🔔 en haut à droite pour activer les rappels
